06 · Fundamento

¿Qué es un clúster?

Conjunto de recursos coordinados para procesar o almacenar información. No confundir número de particiones con número de computadores.

Coordinador / Schedulerelige y supervisa tareas
↓ ↓ ↓
Worker Atrabajo 1
Worker Btrabajo 2
Worker Ctrabajo 3

En S13 levantaremos trabajadores Dask en el MISMO Codespace. Es coordinación real, pero no clúster físico de tres computadores.

07 · Cuatro conceptos

Nodo ≠ partición ≠ worker ≠ réplica

Nodo

Máquina o entorno que aporta CPU, memoria, almacenamiento o red.

Partición

Conjunto lógico de registros o tareas. Pueden existir varias en una máquina.

Worker

Proceso o hilo que recibe tareas del scheduler.

Réplica

Copia extra de datos, usada para disponibilidad o recuperación.

Particionar distribuye trabajo; replicar protege disponibilidad. Son decisiones diferentes.

10 · MapReduce

¿Qué resuelve MapReduce?

Una idea: procesar por partes y combinar parciales correctamente.

DatosLotes con distintos tamaños
→
MAPsuma + cantidad
→
REDUCEsumar parciales
→
Resultadototal / cantidad

¿Se puede hacer en Python puro?

Sí. MapReduce es un patrón. No necesitamos instalar Hadoop para comprenderlo.

¿Se puede hacer mal?

Sí. Si combinamos promedios locales sin considerar tamaños, alteramos el resultado.

11 · Una trampa matemática

El promedio de promedios está mal

Lote 12observaciones
Lote 25observaciones
Lote 3100observaciones
Promedio ingenuo40,33

Media de tres medias

Promedio global correcto3,46

370 / 107 registros

Conserva suma y cantidad en cada partición; después reduce.

12 · Python visible

MapReduce en cinco líneas comprensibles

lotes = [[100, 120], [10, 12, 11, 9, 8], [1] * 100]
parciales = [(sum(x), len(x)) for x in lotes]
total = sum(s for s, n in parciales)
cantidad = sum(n for s, n in parciales)
print(total / cantidad)   # 3.4579...
Se leeCada pareja es (suma, cantidad)
DiceSe preserva peso de cada lote

ErrorPromediar medias

22 · Ejecución diferida

¿Por qué `compute()` importa?

LecturaDataFrame
→
Plantransformaciones diferidas
→
Schedulerorganiza tareas
→
compute()resultado

Antes de compute()

Dask construye una representación del trabajo necesario.

Después de compute()

Materializa una salida de pandas, por ejemplo una serie de conteos.

El costo de coordinar tareas puede superar el costo de contar mil registros.

26 · Texto a números

TF-IDF explicado

Descripción SECOP«servicio de mantenimiento»
→
TF-IDFmatriz numérica
→
Clasificadormodalidad estimada

TF-IDF asigna pesos a términos según su frecuencia dentro del documento y su presencia en el conjunto de entrenamiento. La regresión logística aprende parámetros para distinguir etiquetas.

El vectorizador sólo se ajusta con el entrenamiento, dentro del Pipeline. Hacerlo antes del corte causa fuga estadística.

29 · El control

¿Ganamos algo frente a predecir siempre la mayoría?

Modelo control

DummyClassifier: siempre predice la categoría más frecuente.

Si nuestro modelo no lo supera, debemos revisar el experimento.

Modelo aprendido

32 · Fallas controladas

Una tarea falló. ¿Falló el sistema?

def duplicar(numero):
    if numero < 0:
        raise ValueError("Entrada no válida")
    return numero * 2

# Intenta -1, registra el error, luego prueba 4
# Resultado recuperado esperado: 8

Falla de tarea

Una entrada inválida produce excepción. La tarea puede registrarse o reintentarse.

Falla de nodo

No se simula matando un servidor: es un fenómeno diferente y con garantías distintas.

Evita reintentar escrituras externas sin estrategia de idempotencia. Una tarea reintentada podría duplicar efectos secundarios.
