for psm in [3, 6, 11]:

PSM = modo de segmentación

3: detecta columnas y bloques automáticamente; inicio recomendado para un acta completa.
6: supone un bloque uniforme; útil para recortes.
11: texto disperso; útil en letreros, pero puede desordenar tablas.

La aritmética correcta no garantiza que el OCR leyó la cifra correcta. Debemos volver a la fuente.

10 · LECTURA CRÍTICA

¿Por qué el OCR falla sobre un logotipo?

Una persona lee «Lotería del VALLE · Cambia tu vida». El OCR sobre la foto completa puede devolver símbolos, letras sueltas o nada útil.

Formula una hipótesis antes de ejecutar

La dificultad: letras curvas, color, borde ornamental, texto en distintas líneas y una persona que ocupa muchos píxeles.

Propuesta: aislar la región con letras y usar un modo que espere una línea.

La lectura humana es referencia de comparación. No se introduce artificialmente como resultado del modelo.

11 · SEGMENTACIÓN

PSM no es una calidad: indica la distribución del texto

Cuatro posibilidades de Tesseract

PSM 3: estructura automática, recomendado como inicio para página SECOP.

PSM 6: bloque uniforme de texto.

PSM 7: una sola línea, útil al aislar VALLE.

PSM 11: palabras dispersas en una fotografía.

Qué debes hacer

Abre la fotografía 023 en el visor y cambia su región a Palabra VALLE. Compara PSM 6, 7 y 11 sobre los mismos píxeles.

Resultado: anota la salida real. No supone que uno de los modos siempre funcionará.

Modo de segmentación ≠ confianza ≠ exactitud.

12 · PYTHON EDITABLE

Aprender a recortar una foto: cuatro coordenadas

foto = Image.open("datos/raw/fotos/eltiempo_023.webp")
ancho, alto = foto.size
# EDITA: izquierda, arriba, derecha y abajo
zona = (175/1200, 240/675, 540/1200, 375/675)
caja = (round(ancho*zona[0]), round(alto*zona[1]),
        round(ancho*zona[2]), round(alto*zona[3]))
region = foto.crop(caja)
display(region)
print(pytesseract.image_to_string(
    region, lang="spa", config="--psm 7"
))

Explica línea por línea

size: dimensiones reales del archivo.

zona: porcentajes normalizados para el mismo encuadre.

crop: recorta píxeles; no extrae palabras.

PSM 7: el motor busca una línea.

EDITA AQUÍ: los cuatro límites de zona. ¿Qué ocurre si cortas parte de una letra?

15 · API

Base64 de la fotografía original; JPEG es opcional

from pathlib import Path
import base64

ruta = Path("datos/raw/fotos/eltiempo_023.webp")
# Bytes originales: fue el método probado en Codespaces.
b64 = base64.b64encode(
    ruta.read_bytes()).decode("ascii")
entrada = {"image": b64}

Por qué se hace

Pillow puede convertir WebP a JPEG RGB para comparar tamaños y rendimiento, pero no es un requisito para el arreglo que funcionó. Primero prueba los bytes originales.

Base64 convierte bytes a texto seguro para JSON.

En el cuaderno, NORMALIZAR_JPEG = False usa el archivo original; con True estudias una transformación alternativa. Este paso no es OCR.

16 · VISIÓN

Crear vectores de imágenes sin código oculto

import base64, requests

ruta = "datos/raw/fotos/eltiempo_009.webp"
b64 = base64.b64encode(open(ruta,"rb").read()).decode()
respuesta = requests.post(
    "http://127.0.0.1:11434/api/embed",
    json={"model":"embeddinggemma-2:440m",
          "input":[{"image":b64}]}, timeout=240
)
if not respuesta.ok:
    raise RuntimeError(respuesta.text[:1000])
vector_imagen = respuesta.json()["embeddings"][0]
print(len(vector_imagen))

¿Qué sucede?

Los bytes se codifican en Base64. La imagen se coloca dentro de una lista: "input": [{"image": b64}]. Ollama devuelve una lista de vectores y embeddings[0] selecciona el primero (768 números).

Antes de ejecutar esta celda: bash preparar_embeddinggemma.sh. El 440m admite imagen y texto; el 270m solo texto.

17 · DEPURACIÓN

HTTP 400: lee el mensaje, no solo la excepción

respuesta = requests.post(
    API, json={"model": MODELO,
               "input": [{"image": entrada}]}, timeout=240)
if not respuesta.ok:
    raise RuntimeError(
        f"HTTP {respuesta.status_code}: "
        f"{respuesta.text[:1200]}"
    )
vector = respuesta.json()["embeddings"][0]
print(len(vector))  # Esperado: 768

Comprueba una imagen primero

HTTP 400 significa que el servidor rechazó la solicitud. No basta para determinar si fue formato, versión, modelo o entrada.

Usa "input": [entrada] para mantener un formato uniforme. Envíalo como lista tanto para una imagen como para texto. Mantén el mensaje del servidor para diagnosticar otros errores.

En el cuaderno: prueba 1 → 4 → 8 → 62 imágenes. No ejecutes todo el lote antes de comprobar un archivo.

20 · ASR EDITABLE

Qué significa cada parámetro de Whisper

tiny

Modelo pequeño para demostración CPU. Reconoce voz pero puede confundir términos.

cpu / int8

CPU ejecuta inferencia sin GPU dedicada. INT8 reduce precisión numérica y uso de memoria.

language='es'

Selecciona español. Escucha el WAV antes de comparar lo que transcribe el modelo.

En el único cuaderno cambia N_ASR=3 a 30 después de comprender la transcripción y la referencia MINDS-14.

Escribir la transcripción y revisar errores

from faster_whisper import WhisperModel

modelo = WhisperModel(
    "tiny", device="cpu", compute_type="int8"
)
segmentos, info = modelo.transcribe(
    str(wav), language="es"
)
for s in segmentos:
    print(s.start, s.end, s.text)

Qué explicas

ASR: reconocimiento automático del habla.

Segmentos: texto con tiempos de inicio y fin.

WER: errores de palabra frente a referencia humana del mismo audio.

Que Whisper termine no significa que reconoció todas las palabras correctamente.

22 · ETL

Construye un catálogo, no una pantalla de resultados

import json, pandas as pd

registro = {
  "archivo": str(ruta),
  "modalidad": "foto",
  "sha256": sha256(ruta),
  "texto_corto": "OCR si es legible"
}

with open("outputs/catalogo.jsonl","w") as f:
    f.write(json.dumps(registro) + "\n")
pd.DataFrame([registro]).to_parquet(
    "outputs/catalogo.parquet"
)

E · T · L

Extraer: leer la fuente.

Transformar: crear una fila comparable y auditable.

Cargar: JSONL y Parquet.

Conserva fuente y hash. No publiques datos personales extraídos de actas.
