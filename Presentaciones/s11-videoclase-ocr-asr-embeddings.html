02 · La arquitectura · 04–09 min

Seis transformaciones, una fuente trazable

1 Archivo RAW
2 OCR / ASR
3 Candidatos
4 Catálogo
5 Vector
6 Búsqueda + fuente

Tesseract

Lee letras en imágenes.

Whisper

Reconoce palabras en audio.

EmbeddingGemma 2

Codifica texto como vector para buscar.

Cada herramienta resuelve un problema diferente. Ninguna verifica por sí sola la verdad de la información.

04 · OCR · 09–18 min

De píxeles a texto probable

Ejecuta

python lab.py preparar
python lab.py ocr
cat salidas/ocr.json

Abre el afiche y observa la cifra original.

Entiende el código

texto = pytesseract.image_to_string(
    imagen, lang="spa", config="--psm 6"
)

spa: español. psm 6: bloque de texto.

Verifica sin el programa: ejecuta tesseract salidas/afiche_simulado.png stdout -l spa --psm 6 y compara con la imagen original.

05 · ASR · 18–29 min

De sonido a palabras con segundos

Ejecuta

python lab.py asr
cat salidas/asr.json
python lab.py evaluar-asr

Reproduce el WAV original y escucha una cifra.

Entiende

segmentos, info = modelo.transcribe(
    ruta_audio, language="es", beam_size=1
)

Whisper tiny trabaja en CPU. Registra inicio, fin y texto.

Error útil: que Whisper termine no significa que todos los nombres y cantidades sean correctos. Contrasta escuchando el WAV.

06 · Calidad · 18–29 min

¿Cómo sabemos si se equivocó?

OCR

¿La imagen decía 12 y el OCR recuperó 12?

Comparación humana con los píxeles.

ASR

WER = errores de palabras / palabras de referencia.

Solo se calcula si existe una referencia válida para ese audio.

Regla: una métrica de calidad no sustituye al archivo original. Para confirmar una cifra, hay que volver a escuchar o mirar.

07 · Extracción · 29–36 min

Del texto a candidatos estructurados

Ejecuta

python lab.py extraer
cat salidas/extraccion.json

Conserva siempre

Valor / texto de origen / archivo / hash / segundos, cuando sea audio.

Una fecha detectada por una expresión regular es una candidata. La regla no demuestra que el hecho ocurrió.

08 · ETL · 36–41 min

Guardar para poder repetir y auditar

RAW

Bytes originales sin sobrescribir.

Derivados

Texto OCR o ASR inferido por herramientas.

Catálogo

Ruta, tipo, fuente, transformación, hash y texto.

JSON: objeto estructurado. JSONL: un registro por línea. Parquet: tabla columnar. SHA-256: detecta diferencias de bytes, no certifica autenticidad.

09 · Embeddings · 41–51 min

Buscar por significado, no por caracteres exactos

Ejecuta

python lab.py indexar
python lab.py buscar --consulta \
 "¿Cuántos contratos había?"

Modelo usado: embeddinggemma-2:270m.

Comprueba

El modelo devuelve vectores de 768 dimensiones y un ranking de textos con su fuente.

Una similitud alta NO es una probabilidad de verdad.

Distinción: Whisper transcribe, EmbeddingGemma codifica y el coseno ordena. Ninguno redacta una conclusión comprobada automáticamente.
