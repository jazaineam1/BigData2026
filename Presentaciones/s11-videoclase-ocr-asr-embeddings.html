SHA-256: detectar cambios no es validar una noticia

import hashlib
from pathlib import Path

def sha256(ruta):
    h = hashlib.sha256()
    with Path(ruta).open("rb") as f:
        for bloque in iter(lambda: f.read(1024*1024), b""):
            h.update(bloque)
    return h.hexdigest()

print(sha256(ruta))

Qué hace

Lee el archivo en bloques y calcula una huella de 64 caracteres hexadecimales.

Sirve para: detectar cambios de bytes y verificar integridad de copias.

No sirve para: afirmar que el texto de la imagen es correcto, que existe permiso de redistribución o que un dato es verdadero.

DEFINICIÓNLa ruta ubica un archivo, los bytes son su representación binaria y los píxeles resultan de decodificar la imagen.

PSM = modo de segmentación

3: detecta columnas y bloques automáticamente; inicio recomendado para un acta completa.
6: supone un bloque uniforme; útil para recortes.
11: texto disperso; útil en letreros, pero puede desordenar tablas.

La aritmética correcta no garantiza que el OCR leyó la cifra correcta. Debemos volver a la fuente.

Extraer un importe requiere su etiqueta y contexto

Lo que puede fallar

Una tabla tiene columnas de importes, fechas y observaciones. El OCR puede mezclar filas y asociar un número a la etiqueta equivocada.

No hagas: tomar el primer importe detectado y llamarlo «valor del contrato».

Validación con evidencia

1. Encuentra el fragmento «VALOR DEL CONTRATO».

2. Lee las líneas cercanas.

3. Comprueba el importe en la página.

4. Coteja: 6 × 2.460.000 = 14.760.000.

La igualdad matemática comprueba coherencia, no autenticidad contractual.

Expresión regular: detectar no es confirmar

import re

def fragmento_cercano(texto, etiqueta, n=220):
    m = re.search(etiqueta, texto, re.I)
    if not m:
        return None  # No encontrado
    return texto[m.start():m.start()+n]

print(fragmento_cercano(
    texto, "VALOR DEL CONTRATO"
))

Aprende por qué

re.search: busca una etiqueta dentro del OCR.

m.start(): posición donde comienza la coincidencia.

None: señala ausencia; no es cero ni un texto que debas completar de memoria.

EDITA: n=220→400. ¿El contexto adicional mezcla columnas? Vuelve al PDF para resolverlo.

DEFINICIÓNPSM define cómo segmentar bloques y líneas; una expresión regular encuentra patrones. Ninguno garantiza que una cifra pertenezca al campo correcto.
EDITA AQUÍPSM 3→6 y longitud de contexto 220→400.
OBSERVACambio de líneas recuperadas y etiquetas.
VERIFICAVolver al fragmento de la página.

Logotipo del Valle: recortar y descubrir errores

¿Por qué el OCR falla sobre un logotipo?

Una persona lee «Lotería del VALLE · Cambia tu vida». El OCR sobre la foto completa puede devolver símbolos, letras sueltas o nada útil.

Formula una hipótesis antes de ejecutar

La dificultad: letras curvas, color, borde ornamental, texto en distintas líneas y una persona que ocupa muchos píxeles.

Propuesta: aislar la región con letras y usar un modo que espere una línea.

La lectura humana es referencia de comparación. No se introduce artificialmente como resultado del modelo.

Falsos positivos: una salida larga puede estar equivocada

Resultado bruto

Los OCR de logotipos decorados pueden contener sílabas sueltas, caracteres superpuestos y saltos sin sentido.

Guardar toda la salida permite analizar el problema; recortarla con [:130] puede ocultarlo.

Referencia visual: «Lotería del VALLE» y «Cambia tu vida».

Predicción: lo que realmente devuelve Tesseract, incluso si es incorrecto.

Que Whisper termine no significa que reconoció todas las palabras correctamente.
WER = sustituciones + eliminaciones + inserciones / palabras
Ejemplo editable
1 error / 3 palabras = WER 0,333

S: una palabra distinta.
D: una palabra omitida.
I: una palabra adicional.
N: número de palabras humanas de referencia.
El WER puede superar 1. Si no existe referencia independiente, no puede medirse con rigor.

Sustitución: reconoce otra palabra.

Inserción: inventa una palabra adicional.
