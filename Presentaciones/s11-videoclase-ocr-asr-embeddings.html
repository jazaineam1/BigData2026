17 · HUELLAS

SHA-256: detectar cambios no es validar una noticia

import hashlib
from pathlib import Path

def sha256(ruta):
    h = hashlib.sha256()
    with Path(ruta).open("rb") as f:
        for bloque in iter(lambda: f.read(1024*1024), b""):
            h.update(bloque)
    return h.hexdigest()

print(sha256(ruta))

Qué hace

Lee el archivo en bloques y calcula una huella de 64 caracteres hexadecimales.

Sirve para: detectar cambios de bytes y verificar integridad de copias.

No sirve para: afirmar que el texto de la imagen es correcto, que existe permiso de redistribución o que un dato es verdadero.

22 · EVALUACIÓN

Extraer un importe requiere su etiqueta y contexto

Lo que puede fallar

Una tabla tiene columnas de importes, fechas y observaciones. El OCR puede mezclar filas y asociar un número a la etiqueta equivocada.

No hagas: tomar el primer importe detectado y llamarlo «valor del contrato».

Validación con evidencia

1. Encuentra el fragmento «VALOR DEL CONTRATO».

2. Lee las líneas cercanas.

3. Comprueba el importe en la página.

4. Coteja: 6 × 2.460.000 = 14.760.000.

La igualdad matemática comprueba coherencia, no autenticidad contractual.

23 · EXTRACCIÓN

Expresión regular: detectar no es confirmar

import re

def fragmento_cercano(texto, etiqueta, n=220):
    m = re.search(etiqueta, texto, re.I)
    if not m:
        return None  # No encontrado
    return texto[m.start():m.start()+n]

print(fragmento_cercano(
    texto, "VALOR DEL CONTRATO"
))

Aprende por qué

re.search: busca una etiqueta dentro del OCR.

m.start(): posición donde comienza la coincidencia.

None: señala ausencia; no es cero ni un texto que debas completar de memoria.

EDITA: n=220→400. ¿El contexto adicional mezcla columnas? Vuelve al PDF para resolverlo.

26 · LECTURA CRÍTICA

¿Por qué el OCR falla sobre un logotipo?

Una persona lee «Lotería del VALLE · Cambia tu vida». El OCR sobre la foto completa puede devolver símbolos, letras sueltas o nada útil.

Formula una hipótesis antes de ejecutar

La dificultad: letras curvas, color, borde ornamental, texto en distintas líneas y una persona que ocupa muchos píxeles.

Propuesta: aislar la región con letras y usar un modo que espere una línea.

La lectura humana es referencia de comparación. No se introduce artificialmente como resultado del modelo.

32 · PREPROCESAR

Transformar la imagen es un experimento, no una garantía

Recortar

Reduce distractores: aísla solo la palabra deseada. Evita cortar letras en el borde.

Escalar

LANCZOS interpola píxeles y puede facilitar el reconocimiento de letras pequeñas. No crea nueva información.

Contraste

Separar claros y oscuros puede ayudar o borrar distinciones entre letras de colores.

Experimento válido: mantiene el mismo recorte y PSM 7; cambia solo escala 1→2. Después compara contraste desactivado/activado con los demás parámetros constantes.

36 · BINARIOS

Base64: transporte de bytes, no interpretación visual

import base64
from pathlib import Path

ruta = Path("datos/raw/fotos/eltiempo_023.webp")
contenido = ruta.read_bytes()
cadena = base64.b64encode(contenido).decode("ascii")
print("Bytes originales:", len(contenido))
print("Caracteres Base64:", len(cadena))

¿Qué sucede?

read_bytes obtiene el archivo real, sin modificarlo.

b64encode transporta esos bytes dentro del JSON que enviamos a Ollama.

Base64 NO comprende ni clasifica la fotografía.

La conversión a JPEG RGB es un experimento opcional. El formato de API correcto sigue siendo input: [entrada].

37 · VISIÓN

Crear vectores de imágenes sin código oculto

import base64, requests

ruta = "datos/raw/fotos/eltiempo_009.webp"
b64 = base64.b64encode(open(ruta,"rb").read()).decode()
respuesta = requests.post(
    "http://127.0.0.1:11434/api/embed",
    json={"model":"embeddinggemma-2:440m",
          "input":[{"image":b64}]}, timeout=240
)
if not respuesta.ok:
    raise RuntimeError(respuesta.text[:1000])
vector_imagen = respuesta.json()["embeddings"][0]
print(len(vector_imagen))

¿Qué sucede?

Los bytes se codifican en Base64. La imagen se coloca dentro de una lista: "input": [{"image": b64}]. Ollama devuelve una lista de vectores y embeddings[0] selecciona el primero (768 números).

Antes de ejecutar esta celda: bash preparar_embeddinggemma.sh. El 440m admite imagen y texto; el 270m solo texto.

    raise RuntimeError(
        f"HTTP {respuesta.status_code}: "
        f"{respuesta.text[:1200]}"
    )

Comprueba una imagen primero

HTTP 400 significa que el servidor rechazó la solicitud. No basta para determinar si fue formato, versión, modelo o entrada.

Usa "input": [entrada] para mantener un formato uniforme. Envíalo como lista tanto para una imagen como para texto. Mantén el mensaje del servidor para diagnosticar otros errores.

El numerador es la suma de productos por dimensión. El denominador normaliza por el tamaño de ambos vectores.

En el laboratorio, cada vector tiene 768 dimensiones.

46 · SEÑAL

Cómo calcular la duración de una voz sin inventarla

with sf.SoundFile(io.BytesIO(raw)) as audio:
    hz = audio.samplerate
    canales = audio.channels
    muestras = audio.read(
        dtype="float32", always_2d=True)

mono = muestras.mean(axis=1)
duracion = len(mono) / hz
print(hz, canales, duracion)

Definiciones

Hz: muestras por segundo.

Canales: amplitudes simultáneas (mono/estéreo).

Duración: número de muestras dividido entre la tasa.

Mono: una secuencia de amplitudes.

50 · WER · MÉTRICA

WER = sustituciones + eliminaciones + inserciones / palabras

Ejemplo editable

1 error / 3 palabras = WER 0,333

Cómo interpretar

S: una palabra distinta.

D: una palabra omitida.

I: una palabra adicional.

N: número de palabras humanas de referencia.

El WER puede superar 1. Si no existe referencia independiente, no puede medirse con rigor.

51 · EVALUAR ASR

Aprende más de un error que de una ejecución exitosa

Clasifica el error

54 · ALMACENAMIENTO

JSON, JSONL y Parquet: tres usos de un mismo dato

JSON

Objeto o colección serializada; útil para manifiestos de audio y configuración.

{"licencia":"CC BY 4.0",
 "total":30}

JSONL

Una fila JSON por línea. Permite inspeccionar y procesar registros sucesivos.

{"tipo":"foto","ruta":"..."}
{"tipo":"acta","ruta":"..."}

Parquet

Formato columnar con tipos; permite leer columnas concretas y facilita analítica.
