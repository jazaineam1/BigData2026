Representación

Embedding = un vector para comparar

[0.08, −0.14, …]

El texto se transforma en una posición dentro de un espacio de muchas dimensiones.

No es una explicación humana. Tampoco es “un concepto por dimensión”.
Dimensión

384 componentes no significan 384 palabras

n documentos

n × 384

misma geometría

documentos y consultas deben vivir en una representación compatible.

comparación

la geometría permite ordenar vecinos.

Los ejes son didácticos. En embeddings reales no debes nombrar dimensiones individuales así.

Similitud

Coseno compara orientación

cos(a,b)

producto punto dividido por las normas.

def coseno(a, b):
    return np.dot(a, b) / (
        np.linalg.norm(a) *
        np.linalg.norm(b)
    )
No cometas este error

0.91 no significa “91 % relevante”

Sí puedes decir

“bajo este modelo, estos vectores tienen alta cercanía.”

No puedes decir

“hay 91 % de probabilidad de que el proceso sea correcto.”

La relevancia necesita juicios humanos o un conjunto evaluado.

Cuaderno

Primero la referencia lexical

bm25 = BM25Okapi(corpus_tokens)
scores = bm25.get_scores(tokens(consulta))

Nota metodológica. Esta BM25 local no replica exactamente el analyzer de Elasticsearch S07. Es una línea base didáctica sobre el mismo corpus.
Cuaderno

Luego generamos embeddings

modelo = SentenceTransformer(
    "intfloat/multilingual-e5-small"
)

embeddings = modelo.encode(
    ["passage: " + t for t in textos],
    normalize_embeddings=True
)
Normalizados, el producto punto sirve como coseno.
Búsqueda exacta local

Antes de una base vectorial, NumPy ya demuestra la idea

q = modelo.encode(
    ["query: " + consulta],
    normalize_embeddings=True
)[0]

scores = embeddings @ q
top5 = np.argsort(-scores)[:5]

Con ~2 mil documentos, esto es suficiente para aprender el mecanismo.

Contingencia

Atlas no puede secuestrar la clase

Si funciona

ves persistencia, índice y consulta real.

Si falla/provisiona lento

sigues con búsqueda exacta local. La competencia central ya se logró.

Una herramienta externa es una ruta de implementación, no el objetivo de aprendizaje.
