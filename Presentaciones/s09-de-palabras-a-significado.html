Definiciones antes de usarlas

Cuatro palabras base.

Corpus

Conjunto de documentos sobre el que se busca.

Documento

Unidad recuperable: una fila, contrato, noticia o proceso.

Consulta

Texto o criterio que expresa la necesidad del usuario.

Ranking

Lista ordenada de candidatos según una señal.

Ejemplo del curso. Corpus = procesos SECOP; documento = un proceso; consulta = necesidad escrita; ranking = Top-5 recuperado.

Mapa mental

Lexical, semántica e híbrida.

Recuperación lexical

Usa coincidencia y peso de palabras/términos.

Recuperación semántica

Usa representaciones numéricas para aproximar significado.

No son marcas. Son mecanismos. Una misma herramienta puede implementar varios.

Top-k

Los k primeros resultados del ranking. Si k=5, miramos los cinco mejores candidatos.

Ejemplo

Top-5 para “aviones militares”: cinco procesos ordenados por cercanía.

Definición obligatoria

Embedding: texto convertido en vector.

Embedding

Representación numérica que ubica un texto en un espacio donde podemos comparar cercanía.

Vector

Lista ordenada de números. Ejemplo: [0.08, -0.14, 0.22, ...].

No es una traducción literal. No puedes leer “el componente 17 significa aeronave”.
Definición

Dimensión: cuántos números tiene el vector.

Dimensión

Cantidad de componentes del vector.

Ejemplo pequeño

[0.2, 0.8] tiene 2 dimensiones.

En el cuaderno

multilingual-e5-small produce 384 dimensiones.

Cuando decimos “384 dimensiones” decimos “384 números por documento”, no “384 conceptos humanos”.
Definición

Modelo de embeddings.

Modelo

Función entrenada que transforma texto en vectores comparables.

Ejemplo

intfloat/multilingual-e5-small recibe texto en español y devuelve un vector de 384 números.

documento: "mantenimiento de aeronaves"
modelo E5 → [0.02, -0.31, ..., 0.11]
Regla de uso

E5 usa prefijos: query y passage.

query:

Prefijo para consultas o preguntas del usuario.

passage:

Prefijo para documentos o fragmentos del corpus.

"query: reparación de aviones militares"
"passage: mantenimiento de aeronaves KFIR"
Si mezclas mal la convención, no estás comparando como espera el modelo.
Definición

Similitud: una señal de cercanía.

Similitud

Número que resume qué tan cercanos son dos vectores según una regla.

Similitud coseno

Compara la orientación de dos vectores, no su longitud absoluta.

0.91 no significa 91 % relevante. Significa alta cercanía bajo ese modelo y esa métrica.
LAB 2 · calculadora de coseno

Calcula cercanía antes de confiar en ella.

Usa esto para separar “cercanía geométrica” de “relevancia humana”.
Error frecuente

Score alto ≠ documento correcto.

Falso positivo

Resultado que parece cercano por la señal, pero no responde la necesidad real.

Ejemplo

“mantenimiento de edificio militar” puede parecer cercano a “mantenimiento militar”, pero no habla de aeronaves.

Por eso el laboratorio exige encontrar al menos un falso positivo.

Definición

Base vectorial.

Base vectorial

Sistema que almacena documentos con sus vectores y permite recuperar vecinos cercanos.

Ejemplo

Metadata

Exacto vs aproximado

Exacto vs aproximado.

TérminoDefiniciónEjemplo
ENNExact Nearest Neighbors: busca vecinos de forma exacta según el motor.Útil como referencia o corpus pequeño.
ANNApproximate Nearest Neighbors: aproxima para ganar velocidad.Útil cuando hay muchos vectores.
HNSWAlgoritmo de grafo para navegar hacia vecinos prometedores.No compara ingenuamente contra todo.
Implementación

MongoDB Atlas Vector Search.

Atlas Vector Search

Capacidad de MongoDB Atlas para indexar y consultar vectores almacenados en documentos.

$vectorSearch

Etapa de pipeline que recupera vecinos usando un índice vectorial.

Atlas es una implementación. No es la definición de base vectorial.
LAB 5 · ruta Atlas

Antes de copiar código, entiende los pasos.

  1. Generar embeddings localmente.
  2. Guardar documento + vector + metadata.
  3. Crear índice vectorial.
  4. Esperar queryable=true.
  5. Consultar con $vectorSearch.
Si Atlas tarda, la ruta local con NumPy sigue siendo válida para aprender el mecanismo.
Código con definición

Qué significa cada parte de $vectorSearch.

{
  "$vectorSearch": {
    "index": "s09_vector_index",   // índice vectorial
    "path": "embedding",           // campo donde vive el vector
    "queryVector": q,               // vector de la consulta
    "numCandidates": 50,            // candidatos revisados
    "limit": 5                      // Top-k devuelto
  }
}
LAB 6 · Top-k

Top-k recorta el ranking.

k no mejora el modelo. Solo decide cuántos candidatos inspeccionas.
Definición

Juicio de relevancia.

Juicio de relevancia

Decisión humana o etiquetada sobre si un documento responde a la necesidad.

Ejemplo

“Este proceso sí sirve porque habla de mantenimiento de aeronaves; este no porque habla de edificios”.

Sin juicios de relevancia no hay benchmark serio; hay exploración cualitativa.
