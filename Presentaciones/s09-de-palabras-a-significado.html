TRANSICIÓN

Si las palabras cambian, necesitamos otra representación.

texto → ? → números comparables
DEFINICIÓN

Embedding: texto convertido en vector.

Embedding

Representación numérica aprendida de un texto que permite comparar cercanía.

No significa

No es una explicación humana palabra por palabra.

"mantenimiento de aeronaves" → [0.02, -0.31, ..., 0.11]
DEFINICIÓN

Vector: lista ordenada de números.

Vector

Lista ordenada de componentes. Ejemplo: [0.2, 0.8].

Componente

Cada posición de la lista tiene un valor numérico.

DEFINICIÓN

¿Quién crea esos números?

Modelo de embeddings

Función entrenada que transforma texto en vectores comparables.

Ejemplo

intfloat/multilingual-e5-small genera vectores de 384 dimensiones.

CAJA NO MÁGICA

Dentro de la caja hay etapas.

No profundizamos arquitectura Transformer; necesitamos saber qué objeto sale y cómo compararlo.
DEFINICIÓN

Tokenización del modelo ≠ analyzer de Elasticsearch.

Analyzer S07

Prepara texto para índice invertido y BM25.

Tokenizer del modelo

Parte el texto en unidades que el modelo puede procesar, a veces subtokens.

No uses “token” como si siempre significara lo mismo. Depende del sistema.
DEFINICIONES

Encoder y pooling.

Encoder

Produce representaciones internas contextualizadas de los tokens.

Pooling

Resume varias representaciones en un solo vector del texto.

DEFINICIÓN

Dimensión: cuántos números tiene el vector.

2D didáctico

[0.2, 0.8] tiene 2 dimensiones.

384D real

E5-small produce 384 números por texto.

Cuidado

384 dimensiones no son 384 conceptos humanos.

VISUALIZACIÓN

Una visualización 2D es una analogía.

REGLA DE USO

E5 usa prefijos: query y passage.

query:

Prefijo para consultas o preguntas del usuario.

passage:

Prefijo para documentos o fragmentos del corpus.

query: reparación de aviones militares
passage: mantenimiento de aeronaves KFIR
Si mezclas mal la convención, cambias la forma en que el modelo espera comparar textos.
DEFINICIÓN

Normalizar conserva dirección y fija la norma.

Normalización

Escalar un vector para que su norma sea 1 sin cambiar su orientación.

Por qué importa

Con embeddings normalizados, producto punto y coseno coinciden.

CÓDIGO EXPLICADO

Por eso el cuaderno puede usar producto punto.

embeddings = modelo.encode(
    textos,
    normalize_embeddings=True
)

q = modelo.encode(
    ["query: " + consulta],
    normalize_embeddings=True
)[0]

scores = embeddings @ q
cos(q,d) = q · d
Esta igualdad funciona porque los vectores fueron normalizados.

No digas: 0.91 = 91 % relevante. Di: alta cercanía bajo ese modelo y esa métrica.

FILTROS

Metadata

Datos descriptivos: entidad, fecha, modalidad, URL.

Filtro

Condición que restringe dónde buscar antes o durante la recuperación.

EXACTO

ENN: vecinos exactos.

Exact Nearest Neighbors: revisa exhaustivamente el universo permitido según el motor. Útil como referencia o corpus pequeño.
APROXIMADO

ANN: vecinos aproximados.

Approximate Nearest Neighbors: reduce la búsqueda para mejorar latencia. Lo aproximado es el proceso de recuperación, no el juicio de relevancia.
INTUICIÓN

HNSW: navegar en vez de revisar todo.

TRADE-OFF

Gráfico conceptual: se ajusta con datos reales, no por fe.
