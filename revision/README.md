# Aula alternativa de revisión

Esta carpeta es el punto de entrada de la reconstrucción pedagógica experimental. No es el sitio publicado ni sustituye el LMS.

- Portada: [index.html](index.html).
- Presentación: [clases-reconstruidas.html](../Presentaciones/clases-reconstruidas.html).
- [Curso oficial sin cambios](https://jazaineam1.github.io/BigData2026/).
- [Informe de implementación](../docs/implementacion-auditoria-sesiones.md).

Para visualizar sin publicar en GitHub Pages: usar un visor estático externo del HTML público (sujeto a disponibilidad del proveedor) o abrir el archivo autónomo de presentación en un navegador. Para servir la portada y navegar de forma local, desde una copia de esta rama ejecutar `python -m http.server 8000` y abrir `http://localhost:8000/revision/`. No requiere iniciar Codespaces para ver la presentación. Los cuadernos conservan sus enlaces a GitHub y entornos correspondientes.

**Prohibición de integración:** no fusionar esta rama con main ni desplegarla en el GitHub Pages oficial sin autorización expresa. La revisión no está certificada y no contiene formularios de autenticación del LMS. No lanzar workflows de producción para previsualizarla.
