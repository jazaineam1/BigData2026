El código y los formatos del ETL de Laura

Por qué: Laura necesita saber exactamente qué se ejecutó, no solo pulsar «transformar». La herramienta procesa localmente; Colab muestra el código Python completo y el ETL por bloques para audios largos.

Ver código esencial: audio por bloques (Python/Colab) 
import soundfile as sf
# Fragmentos de 10 segundos; el RAW original no se modifica.
with sf.SoundFile(ruta_wav) as entrada:
    for bloque in entrada.blocks(blocksize=entrada.samplerate * 10):
        transformar_bloque(bloque)  # explicado paso a paso en S11
        guardar_derivado_verificado()

Cómo se lee: blocks avanza por el archivo completo, sin imponer un minuto. El ejemplo anterior es un esquema didáctico, no código ejecutable sin definir esas funciones; el cuaderno tiene la implementación real.

¿Qué son JSON, JSONL y Parquet?

JSON: un documento con objetos o listas. JSONL: una fila JSON independiente por línea, fácil de anexar y leer secuencialmente. Parquet: archivo binario columnar para consultar columnas y conservar tipos. Aquí descargamos catalogo.jsonl; en Colab puedes convertirlo a Parquet y reabrirlo.

JSON:  [{"modality":"image"},{"modality":"audio"}]
JSONL: {"modality":"image"}
       {"modality":"audio"}
¿Qué contiene cada carpeta del ZIP?

raw/: originales; derived/: copias transformadas; catalogo.jsonl: una fila por activo; manifest.json: índices y huellas SHA-256. No se conserva información secreta en un navegador público.

Prueba autónoma: sube una imagen y un audio largo, observa la etapa T y descarga el ZIP. En el cuaderno ejecuta 6B para comparar formatos y 6C para recuperar los archivos sin repetir el ETL.

T · Transformar: ¿qué cambió y qué permanece?

Se conserva la proporción; nunca aumenta la resolución original.

Audio: salida PCM16 mono, 16 000 muestras/s. Cambia la ventana, el inicio o la ganancia para comparar una señal real, no una transcripción.

Ganancia 0 % → silencio medible; una señal saturada puede recortarse.

Comparación acústica: observa RMS, pico, porcentaje de recorte y cruces por cero. Aumentar el volumen puede cambiar RMS sin cambiar las palabras de la grabación.
Descripción automatizada: se informa resolución, luminancia, histograma o energía. No se inventan objetos, palabras ni hechos que no hayan sido reconocidos por un modelo.
