Este tutorial asume que nunca has usado Neo4j. Al terminar tendrás una instancia AuraDB Free funcionando y Colab podrá conectarse a ella.

Antes de hacer clic

Neo4j ≠ AuraDB ≠ Cypher ≠ Driver

Esta distinción evita la confusión más común de la sesión.

Neo4jLa base de datos de grafos. Guarda nodos, relaciones y propiedades y permite recorrer conexiones.
AuraDBEl servicio administrado en la nube donde hoy ejecutaremos Neo4j sin instalar un servidor en tu computador.
CypherEl lenguaje con el que consultas Neo4j. MATCH, MERGE y RETURN son palabras de Cypher.
Neo4j DriverLa librería que permite a Python/Colab conectarse a una instancia Neo4j, incluida AuraDB.
Colab → Neo4j Driver → AuraDB → Neo4j
                             ↑
                           Cypher
Frase para recordar: hoy aprendes Neo4j; AuraDB es el lugar administrado donde lo ejecutas.

Paso 5 · prueba mínima

Comprueba que Neo4j responde antes de cargar datos

Copia exactamente esta consulta en Query y ejecútala:

RETURN 1 AS conexion;
Esperado: una fila con la columna conexion y el valor 1.

¿Qué demuestra?

✓
La interfaz Query puede hablar con tu instancia.
✓
Tus credenciales funcionan en la consola.

¿Qué NO demuestra?

×
Que el grafo de Compras Claras ya esté cargado.
×
Que el modelo Entidad → Proceso → Proveedor sea correcto.
×
Que Python pueda conectarse todavía.
Regla de diagnóstico: primero prueba la plataforma; después prueba Python. Así no mezclas dos problemas diferentes.

Paso 7

Conecta Python sin escribir la contraseña en pantalla

from neo4j import GraphDatabase
from getpass import getpass

URI = input("Connection URI: ").strip()
USER = input("User name: ").strip()
PASSWORD = getpass("Password: ")

driver = GraphDatabase.driver(
    URI,
    auth=(USER, PASSWORD)
)

driver.verify_connectivity()
print("Conexión Neo4j verificada")
GraphDatabase.driver(...) configura el cliente con la URI y las credenciales.
getpass() permite escribir la contraseña sin dejarla visible en la celda.
verify_connectivity() obliga al driver a comprobar que realmente puede llegar a la base.
Esperado: Conexión Neo4j verificada.
