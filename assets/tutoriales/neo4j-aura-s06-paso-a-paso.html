AuraDB desde cero

Este tutorial solo te ayuda a entrar al servicio y dejarlo listo. La teoría, la construcción de nodos y el aprendizaje de Cypher están en Neo4j y Cypher de cero al caso Compras Claras.

1. Qué es cada cosa

Neo4j = motor/base de datos de grafos. AuraDB = servicio administrado en la nube donde corre Neo4j. Aura Query = interfaz donde escribes y ejecutas consultas. Cypher = lenguaje de consulta.

No son cuatro productos equivalentes: forman una cadena. AuraDB aloja Neo4j; Aura Query es la pantalla; Cypher es el lenguaje.

2. Entra a Aura

Abre la consola de Neo4j Aura con tu cuenta. Crea o reutiliza una instancia de práctica de AuraDB. No necesitas conocer todavía nodos ni relaciones.

3. Guarda tres datos

Necesitas exactamente: Connection URI, User name y Password.

La contraseña es privada. No la pegues en el notebook como texto visible ni la subas a GitHub.

4. Abre Query

En tu instancia abre Query. Esa es la pantalla donde ejecutarás el curso zero-to-hero. Verás un editor, un botón Run y, después de cada consulta, vistas de resultado como Graph y Table.

5. Primera prueba

RETURN 1 AS conexion

Presiona Run y abre Table.

Resultado esperado: una columna conexion con valor 1. Eso solo verifica que Query responde; todavía no has creado ningún nodo.

6. Qué haces después

Abre el tutorial Neo4j y Cypher de cero al caso Compras Claras. Su primer ejercicio real será crear manualmente un nodo EntidadDemo con CREATE. No saltes a hub, WITH, UNWIND ni a la carga real.

7. Vuelve a Colab cuando el tutorial lo indique

Después de construir y consultar el grafo de juguete, en Colab elige AURA. Copia URI y usuario; escribe la contraseña cuando Colab la solicite de forma oculta.

No subas el JSON de S5 a Aura. Ese archivo se carga en Colab; Aura recibe únicamente las consultas y datos que el notebook envía.

8. Si no puedes usar Aura

Elige RESPALDO. Podrás continuar con pandas y leer las consultas, pero la práctica manual de Graph/Query queda pendiente porque requiere un motor Neo4j disponible.
