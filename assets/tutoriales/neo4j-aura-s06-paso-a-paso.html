1 · Antes de crear nada

Una sola instancia Free es suficiente

Si nunca usaste Aura

Entra a Aura Console, crea o inicia sesión y elige AuraDB. Selecciona el nivel Free.

Si ya tienes una Free

Reutilízala. No intentes crear una segunda instancia Free. Si aparece pausada, reanúdala.

OJO. Neo4j documenta actualmente una sola instancia Free por cuenta. La práctica no necesita Graph Data Science, vector optimization ni una instancia de pago.

PARA LLEVAR. Si esta prueba funciona y Python después falla, ya sabes que la base está viva: el problema está en URI, credenciales, red o driver.

5 · Qué vamos a cargar

El candidato no necesita tener proveedor

(:Entidad)-[:PUBLICA]→(:Proceso)

(:Proceso histórico)-[:ADJUDICADO_A]→(:Proveedor)

El proceso que llega desde S5 puede seguir sin adjudicación. Es el ancla. El historial adjudicado de su entidad aporta los proveedores y las conexiones.

Error frecuente. Inventar un proveedor para el candidato solo para que el dibujo “quede bonito”. Si el dato no existe, el grafo debe mostrar esa ausencia.
6 · Cypher mínimo

Lee el patrón antes de memorizar comandos

(e:Entidad)-[:PUBLICA]->(p:Proceso)-[:ADJUDICADO_A]->(v:Proveedor)

MERGE

Encuentra el patrón o lo crea. Lo usamos para que repetir la carga no duplique actores.

MATCH

Busca patrones existentes.

WHERE

Filtra lo que ya encontró el patrón.

RETURN

Define qué sale de la consulta.

7 · Antes de MERGE

Primero, identificadores únicos

CREATE CONSTRAINT entidad_nit IF NOT EXISTS
FOR (e:Entidad) REQUIRE e.nit IS UNIQUE;

CREATE CONSTRAINT proceso_id IF NOT EXISTS
FOR (p:Proceso) REQUIRE p.id IS UNIQUE;

CREATE CONSTRAINT proveedor_nit IF NOT EXISTS
FOR (v:Proveedor) REQUIRE v.nit IS UNIQUE;

Qué observar. Puedes volver a ejecutar estas sentencias sin crear tres restricciones nuevas gracias a IF NOT EXISTS.

8 · Conectar Colab

Usa las credenciales de la instancia

from neo4j import GraphDatabase
from getpass import getpass

URI = input("Connection URI: ").strip()
USER = input("User name: ").strip()
PASSWORD = getpass("Password: ")

driver = GraphDatabase.driver(URI, auth=(USER, PASSWORD))
driver.verify_connectivity()

El driver oficial documenta GraphDatabase.driver(...) y verify_connectivity() como comprobación explícita de conexión.

9 · Si algo falla

Diagnóstico rápido

AuthenticationError

Revisa usuario/contraseña. No regeneres datos ni cambies Cypher.

ServiceUnavailable / timeout

Revisa URI, que la instancia esté activa y la conectividad de la red.

Query funciona, Python no

La base está viva. Compara URI y credenciales usadas por el driver.

Tu ancla no tiene historial

No es un error de Neo4j. El notebook usa una ancla pedagógica real y registra esa ausencia como límite.
