AuraDB desde cero

Este tutorial solo sirve para entrar al servicio y dejarlo listo. La teoría y Cypher están en el Mini curso visual.

1. Qué es cada cosa

Neo4j = motor. AuraDB = servicio en la nube. Aura Query = pantalla para consultar. Cypher = lenguaje de consulta.

2. Entra a Aura

Abre la consola de Neo4j Aura con tu cuenta. Crea o reutiliza una instancia de práctica de AuraDB. No necesitas entender todavía nodos ni relaciones.

3. Guarda tres datos

Necesitas exactamente: Connection URI, User name y Password.

La contraseña es privada. No la pegues en el notebook como texto visible ni la subas a GitHub.

4. Abre Query

En tu instancia abre la herramienta Query. Verás un editor y un botón Run.

5. Primera prueba

RETURN 1 AS conexion

Presiona Run. Abre Table.

Resultado esperado: una columna conexion y el valor 1.

6. Vuelve a Colab

En la celda de conexión elige AURA. Copia URI y usuario; escribe la contraseña cuando Colab la solicite de forma oculta.

7. Si no puedes usar Aura

Elige RESPALDO. Podrás continuar con pandas, pero el cuaderno indicará claramente que la ejecución real de Cypher queda pendiente.

8. Qué sigue

Regresa al cuaderno y abre Mini curso de Cypher en Aura Query. Allí empezarás por MATCH (e:Entidad); no saltes directamente a hubs o caminos largos.
