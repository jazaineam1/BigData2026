AuraDB desde cero

Este tutorial solo responde una pregunta: ¿cómo creo o abro una instancia Neo4j en Aura y verifico que funciona?

Cuatro nombres: Neo4j = motor de grafos · AuraDB = servicio en la nube · Cypher = lenguaje de consulta · Aura Query = editor donde escribes Cypher.

1. Entra a Aura Console

  1. Abre Aura Console ↗.
  2. Inicia sesión.
  3. Elige AuraDB, no AuraDS.
Qué buscas en la pantalla
Producto: AuraDB
Instancias

2. Crea o reutiliza una instancia

Si ya tienes una instancia de práctica, úsala. Si no, crea una instancia AuraDB disponible para tu cuenta. Nombre sugerido:

compras-claras-s06
Hoy no necesitas Graph Data Science ni configuraciones avanzadas. El objetivo es tener Neo4j disponible para consultas Cypher básicas.

3. Guarda tres datos

Al crear o abrir la instancia necesitarás estos datos para Colab:

URI
neo4j+s://...
Usuario
neo4j
Contraseña
••••••••
Nombre de instancia
compras-claras-s06

No publiques la contraseña en GitHub ni la pegues en una celda visible.

4. Abre Aura Query

Dentro de la instancia abre Query. Ese es el lugar donde escribirás Cypher.

RETURN 1 AS conexion

Presiona Run.

Resultado esperado: en Table aparece una columna conexion con el valor 1. Si eso ocurre, Neo4j está respondiendo.

5. Vuelve a Colab y conecta el Driver

En el cuaderno S06 selecciona Aura como modo de ejecución. La celda te pedirá URI, usuario y contraseña. El código de conexión está oculto porque no es el contenido que debes memorizar.

No subas el JSON de S5 a Aura. El archivo s05_ancla_s06.json se usa en Colab para recuperar el proceso y la entidad elegidos. Aura recibe los datos del grafo mediante las celdas de carga del cuaderno.

6. ¿Qué hace Colab y qué hace Aura?

Colab

Lee CSV/JSON, prepara datos y usa el Driver.

AuraDB / Neo4j

Guarda nodos/relaciones y ejecuta Cypher.

Flujo: Colab → Driver de Neo4j → AuraDB → Neo4j.

7. Cuando ya conectó

Regresa al cuaderno y ejecuta las celdas de carga. Luego abre el Mini curso visual de Cypher. Allí aprenderás MATCH, relaciones, caminos, grado y hub.

Prueba de éxito

Antes de continuar debes poder decir:

“AuraDB es donde está mi instancia Neo4j; Cypher es el lenguaje; Aura Query es donde ejecuto las consultas. Ya comprobé RETURN 1 AS conexion.”
