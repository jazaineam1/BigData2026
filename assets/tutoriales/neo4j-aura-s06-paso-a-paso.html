Vocabulario

Neo4j ≠ AuraDB ≠ Cypher ≠ Driver

AuraDBServicio administrado donde hoy vive la base.
CypherLenguaje: MATCH, MERGE, RETURN…
DriverConector para que Python/Colab ejecute Cypher.
Colab → Neo4j Driver → AuraDB → Neo4j
Cypher viaja por esa conexión.

Graph Lab · navegación

Zoom, Fit, arrastrar y expandir

ZoomAcércate a un subgrafo; usa controles o scroll compatible.
FitRecupera todo el resultado dentro del marco.
DragArrastra nodos para separar líneas cruzadas.
ExpandDoble clic o menú contextual, según versión, para explorar vecinos.
No expandas todo. Una red de cientos de nodos se vuelve una “bola de pelo”. Empieza con LIMIT 20 y amplía solo el nodo que investigas.

WOW 1

Encuentra el proveedor que conecta más entidades

MATCH (v:Proveedor)<-[:ADJUDICADO_A]-(p:Proceso)<-[:PUBLICA]-(e:Entidad)
WITH v, count(DISTINCT e) AS entidades,
        count(DISTINCT p) AS grado_adjudicaciones
ORDER BY entidades DESC, grado_adjudicaciones DESC, v.nit ASC
LIMIT 1

MATCH camino=(e:Entidad)-[:PUBLICA]->(:Proceso)-[:ADJUDICADO_A]->(v)
RETURN camino
LIMIT 40
La primera parte elige el hub. La segunda devuelve los caminos para que Graph los dibuje.

WOW 2

Del ancla a otras entidades: cuatro relaciones

El notebook imprime una consulta con el NIT de tu entidad de trabajo.

MATCH (ancla:Entidad {...})-[:PUBLICA]->(:Proceso)-[:ADJUDICADO_A]->(v:Proveedor)
...
MATCH camino=(ancla)-[:PUBLICA]->(:Proceso)-[:ADJUDICADO_A]->(v)
             <-[:ADJUDICADO_A]-(:Proceso)<-[:PUBLICA]-(otra:Entidad)
RETURN camino
LIMIT 30
Lee el camino desde el ancla hasta el proveedor y luego “regresa” por relaciones entrantes hacia otras entidades.

Cierre

La meta no era “hacer círculos bonitos”

La meta era traducir una pregunta de negocio a un patrón, ejecutarlo, comprobarlo y usar la vista gráfica para explicar el camino.
