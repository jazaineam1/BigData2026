Antes de empezar

Cuatro palabras que vas a usar hoy, explicadas sin dar nada por sabido

PalabraQué es
Neo4jun programa para guardar información — como MongoDB o Cassandra que ya viste, pero pensado para cuando lo importante son las conexiones entre las cosas (quién le vendió a quién). En vez de tablas o documentos, guarda "puntos" (nodos) unidos por "líneas" (relaciones).
Cypherel idioma con el que le hablas a Neo4j para pedirle cosas — el equivalente de SQL para una base de datos normal, o de find() para MongoDB. Palabras como MATCH (buscar), MERGE (crear) y RETURN (mostrar resultado) son ese idioma.
AuraDBla versión de Neo4j que vive en internet, para no instalar nada en tu computador. Es "Neo4j en la nube", igual que Atlas es "MongoDB en la nube".
OJO — confusión frecuente. Astra NO es lo mismo que Aura. Astra es la nube de Cassandra (la que viste en la sesión 5, para contar cosas repetidas muchas veces). Aura es la nube de Neo4j (hoy, para relaciones). Son primos, no la misma cosa — cada uno es "la nube" de una base de datos distinta. Hoy solo usas Aura.

Paso 5 · Cypher mínimo

Reconoce seis piezas y vuelve al caso

Recuerda: Cypher es el idioma con el que le hablas a Neo4j — como SQL le habla a una base de datos normal. Estas seis palabras son casi todo el vocabulario que necesitas hoy.

PiezaQué haceError frecuente
MERGEencuentra o crea un patróncreer que siempre duplica
MATCHbusca un patrón existenteignorar la relación
WHEREfiltra coincidenciasfiltrar sin entender el patrón
WITHencadena una etapaperder variables
RETURNdefine la salidaconfundir salida con persistencia
ORDER BY / LIMITordena y acotaasumir orden implícito

Paso 6

Las restricciones fijan identidad

Piénsalo como tu cédula. No puede haber dos personas con la misma cédula — es una regla del registro civil. Estas tres líneas le dicen exactamente esa regla a Neo4j: "nunca permitas dos nodos Entidad con el mismo NIT — el NIT es su cédula". Lo mismo para Proceso (con su ID) y Proveedor (con su NIT).
¿Por qué la necesitas? Vas a cargar más de 2.000 filas, y muchas mencionan a la MISMA entidad varias veces (porque publicó varios procesos). Sin esta regla, Neo4j crearía una copia nueva de "Alcaldía de Bogotá" cada vez que aparezca en una fila distinta — terminarías con 50 copias en vez de una sola.
CREATE CONSTRAINT entidad_nit IF NOT EXISTS
FOR (e:Entidad) REQUIRE e.nit IS UNIQUE;

CREATE CONSTRAINT proceso_id IF NOT EXISTS
FOR (p:Proceso) REQUIRE p.id IS UNIQUE;

CREATE CONSTRAINT proveedor_nit IF NOT EXISTS
FOR (v:Proveedor) REQUIRE v.nit IS UNIQUE;
¿Y el IF NOT EXISTS? Significa "si esta regla ya existe, no la crees otra vez ni des error" — para poder ejecutar la celda las veces que necesites sin que se rompa.
Paso 7

Conecta Colab con el driver oficial

Un driver es el conector que le permite a Python hablar con Neo4j — como un adaptador entre dos aparatos que, sin él, no podrían comunicarse. Ya lo usaste con MongoDB (pymongo) y con Cassandra (cassandra-driver); aquí es neo4j, el oficial.

from neo4j import GraphDatabase
from getpass import getpass

URI = input("Connection URI: ").strip()
USER = input("User name: ").strip()
PASSWORD = getpass("Password: ")

driver = GraphDatabase.driver(
    URI, auth=(USER, PASSWORD)
)
driver.verify_connectivity()
Esperado: la celda termina sin excepción y el notebook imprime “Conexión Neo4j verificada”.

Comprueba el NIT usado y que la carga terminó.

Tour del panel

Bloom — explora el grafo sin escribir Cypher

Bloom dibuja el grafo completo (o un patrón que busques) y lo deja explorar arrastrando: doble clic en un nodo para expandir sus vecinos, clic para ver sus propiedades.

Para qué te sirve hoy. Después de cargar Compras Claras, abre Bloom, busca tu entidad ancla y expande sus vecinos con doble clic — es otra forma de ver lo mismo que ya viste con RETURN camino en Query, pero sin escribir nada.

Tour del panel

Dashboards — convierte una consulta en un gráfico

Guarda una consulta Cypher como una tarjeta de gráfico (barras, tabla, número grande) y arma un panel con varias tarjetas juntas.

Ejemplo con tu caso. Una tarjeta con MATCH (v:Proveedor)<-[:ADJUDICADO_A]-() RETURN v.nombre, count(*) ordenada de mayor a menor, mostrada como barras — la misma pregunta que ya respondiste en pandas y en Neo4j, ahora como gráfico permanente.

Import — cargar CSV sin código

Import deja arrastrar un CSV, mapear sus columnas a nodos y relaciones, y cargarlo sin escribir Cypher.

Por qué hoy no lo usamos. El curso carga con Python (UNWIND + MERGE) a propósito: así la carga queda en un archivo versionado en Git, se puede repetir exactamente igual, y no depende de que alguien recuerde qué mapeo de columnas usó por última vez en la interfaz.
