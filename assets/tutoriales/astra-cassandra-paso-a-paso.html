Paso 5

Crea la tabla diseñada para la pregunta

USE compras_claras;

CREATE TABLE IF NOT EXISTS prioridades_por_corte_departamento (
  corte date,
  departamento text,
  valor_base bigint,
  id_proceso text,
  entidad text,
  estado_revision text,
  url_secop text,
  criterio text,
  PRIMARY KEY ((corte, departamento), valor_base, id_proceso)
) WITH CLUSTERING ORDER BY (valor_base DESC, id_proceso ASC);
(corte, departamento)

localiza la partición.

valor_base DESC

deja los más caros primero.

id_proceso ASC

desempata de forma estable.

No uses CREATE KEYSPACE. Astra Serverless crea/gestiona los keyspaces desde el portal.
Paso 6

INSERT y SELECT: prueba una fila

INSERT INTO compras_claras.prioridades_por_corte_departamento
(corte,departamento,valor_base,id_proceso,entidad,estado_revision,url_secop,criterio)
VALUES ('2026-09-03','Distrito Capital de Bogotá',168750000,
'CO1.REQ.5407319','MINISTERIO DEL DEPORTE','pendiente','',
'entidad en prensa; contratación directa; 0 respuestas');

SELECT id_proceso,entidad,valor_base,estado_revision
FROM compras_claras.prioridades_por_corte_departamento
WHERE corte='2026-09-03'
  AND departamento='Distrito Capital de Bogotá'
LIMIT 5;
Esperado: aparece CO1.REQ.5407319 con valor $168.750.000.
Paso 7

UPDATE y DELETE sin destruir la bandeja

UPDATE compras_claras.prioridades_por_corte_departamento
SET estado_revision='en_revision'
WHERE corte='2026-09-03'
AND departamento='Distrito Capital de Bogotá'
AND valor_base=168750000
AND id_proceso='CO1.REQ.5407319';

Para DELETE, el cuaderno crea después una fila centinela S05-DEMO y borra solo esa fila.

Así practicas borrar sin dañar la bandeja real.
Error plantado

La columna existe, pero esta tabla no fue diseñada para buscar por ella

SELECT *
FROM compras_claras.prioridades_por_corte_departamento
WHERE entidad='MINISTERIO DEL DEPORTE';
Predice antes de ejecutar. entidad no identifica la partición. Si la herramienta te sugiere ALLOW FILTERING, no lo leas como “faltaba esa sintaxis”: el problema es el patrón de acceso.
Decisión: si buscar por entidad se vuelve una necesidad real, diseña otra tabla para esa consulta.

Paso 9

Cuatro objetos antes de volver a Colab

SCB

certificados + datos de conexión de esta base.

Application token

autentica y autoriza.

"token"

usuario literal que recibe el driver.

Cluster / Session: el cliente Python abre la conexión y envía CQL. El cuaderno te pedirá el ZIP y el token sin imprimir el secreto.
