Paso 4

Selecciona keyspace y crea tabla

USE compras_claras;

CREATE TABLE IF NOT EXISTS prioridades_por_corte_departamento (
  corte date, departamento text, valor_base bigint,
  id_proceso text, entidad text, estado_revision text,
  url_secop text, criterio text,
  PRIMARY KEY ((corte, departamento), valor_base, id_proceso)
) WITH CLUSTERING ORDER BY (valor_base DESC, id_proceso ASC);
No uses CREATE KEYSPACE. Astra crea el keyspace desde el portal.

Error plantado

La columna existe… pero la consulta no encaja

SELECT *
FROM compras_claras.prioridades_por_corte_departamento
WHERE entidad='MINISTERIO DEL DEPORTE';
Predice antes de ejecutar. La tabla no está particionada por entidad.

Si aparece ALLOW FILTERING, no lo leas como “la sintaxis que faltaba”, sino como una advertencia de que este no es el patrón de acceso para el que diseñaste la tabla.

Paso 9

Connection details — nombre vigente en 2026

Desde el 9-jul-2026, en Serverless non-vector DataStax reemplazó Connect por Connection details.

  1. Vuelve a tu base y abre Connection details.
  2. Get Secure Connect Bundle → Download SCB.
  3. Conserva el ZIP completo.
  4. Genera un application token para la base.
SECRETO. No publiques token ni SCB en GitHub o en el chat.
Paso 10

SCB, token y el usuario literal “token”

SCB

certificados y datos de conexión mTLS.

Application token

autentica y autoriza.

"token"

usuario literal del driver con token unificado.

Un SCB pertenece a una base/región específica; no lo reutilices como si fuera universal.
