El mapa de herramientas

Tesseract

Ve píxeles y propone caracteres (OCR).

Faster-Whisper

Reglas/regex

Encuentran fechas, cifras y referencias en el texto.

Python/ETL

Coordina archivos, transforma, carga y guarda origen.

Ollama + EmbeddingGemma 2

Convierte texto en vectores para buscar por significado.

SHA-256

Detecta cambios de bytes. No verifica la verdad de una noticia.

Regla de la clase: un texto extraído es una hipótesis. Una respuesta de búsqueda es un candidato. La evidencia exige mirar o escuchar la fuente.

01 / Preparar el entorno

En GitHub abre BigData2026 → Code → Codespaces → New with options → S11 · OCR, voz y EmbeddingGemma 2. No selecciones Airflow.

cd Laboratorios/S11_Codespaces
python --version
tesseract --list-langs
bash probar_todo.sh --ligero

Comprueba: el idioma spa aparece y la prueba acaba en OK. La prueba ligera no sustituye la inferencia real de Whisper/Ollama.

Codespaces tiene cuotas de CPU/almacenamiento. Mantén el puerto 8501 privado, evita subir datos personales y detén la máquina al terminar.

02 / Dos fuentes controladas

python lab.py preparar
sha256sum salidas/afiche_simulado.png salidas/voz_simulada.wav
cat salidas/origen.json

Abre salidas/afiche_simulado.png y reproduce salidas/voz_simulada.wav. Estos archivos son ficticios; fueron generados para enseñar y no representan noticias reales.

Pregunta: ¿qué distingue el original, un texto extraído y una representación vectorial?

03 / OCR: leer píxeles

python lab.py ocr
cat salidas/ocr.json
tesseract salidas/afiche_simulado.png stdout -l spa --psm 6

Una línea importante

texto = pytesseract.image_to_string(
    imagen, lang="spa", config="--psm 6"
)

Qué comprobar

spa: idioma español. psm 6: bloque uniforme. La CLI ejecuta el mismo motor por otra ruta; verifica también visualmente números y letras del PNG.

Comprensión rápida: si Tesseract encuentra «12», ¿significa que hubo 12 contratos reales?

04 / ASR: reconocer el habla

python lab.py asr
cat salidas/asr.json
python lab.py evaluar-asr
cat salidas/evaluacion_asr.json

Whisper tiny escucha el WAV, entrega palabras y marca inicio_s y fin_s. La primera ejecución descarga el modelo y en CPU puede tardar.

Verificación: reproduce el WAV, escucha una cifra y compárala con la transcripción. WER es la tasa de errores de palabra, calculable aquí porque se conoce la frase de referencia del audio sintético. No inventes WER para una grabación sin referencia.

Una señal RMS o un espectrograma no identifica palabras. Para archivos largos o extensiones engañosas, primero inspecciona el códec con ffprobe.

05 / Extracción y ETL

python lab.py extraer
cat salidas/extraccion.json
E: Extraer

Leer el archivo original y el texto probable.

T: Transformar

Detectar candidatos: fechas y cantidades, preservando origen.

L: Cargar

Guardar JSON/JSONL/Parquet y manifiesto para recuperar.

JSON: documento estructurado. JSONL: un registro por línea. Parquet: columnas tipadas. SHA-256: integridad de bytes, no legitimidad de la fuente.

06 / Embeddings y búsqueda

bash iniciar_ollama.sh
python lab.py indexar
python lab.py buscar --consulta "¿Cuántos contratos se mencionaron?"
python lab.py buscar --consulta "¿Qué valor se indicó?"

EmbeddingGemma 2:270m codifica texto con vectores de 768 dimensiones. No escucha el WAV directamente ni escribe una respuesta como un chatbot.

Comprueba fuera de lab.py:

curl -fsS http://127.0.0.1:11434/api/embed \
 -H 'Content-Type: application/json' \
 -d '{"model":"embeddinggemma-2:270m","input":"Un contrato de ejemplo"}' \
 | python -c 'import json,sys; print(len(json.load(sys.stdin)["embeddings"][0]))'

Debe mostrar 768. Abre salidas/indice.json: encuentra fuente y SHA-256 de cada fragmento. El coseno ordena por similitud, no por verdad.

07 / Prueba independiente

python verificar_independiente.py --caso lab --modelo

El verificador separado recalcula hashes, ejecuta Tesseract desde su CLI, controla segmentos de ASR y hace una consulta HTTP directa al modelo. Muestra avisos cuando falta validación humana.

La diferencia: ejecutar sin fallos comprueba el funcionamiento técnico. Leer el original y encontrar la cifra correcta comprueba calidad.

08 / Usa el mismo motor en otro proyecto

No necesitas copiar 400 líneas: cambia la carpeta y tus archivos. Para reproducir el ejercicio con las dos modalidades iniciales:

python proyecto.py iniciar --destino proyectos/mi_reto
cp salidas/afiche_simulado.png proyectos/mi_reto/entradas/imagenes/
cp salidas/voz_simulada.wav proyectos/mi_reto/entradas/audios/
python proyecto.py plan --config proyectos/mi_reto/config.json
python proyecto.py procesar --config proyectos/mi_reto/config.json
python proyecto.py indexar --config proyectos/mi_reto/config.json
python proyecto.py buscar --config proyectos/mi_reto/config.json --consulta "¿Cuántos contratos?"
python proyecto.py auditar --config proyectos/mi_reto/config.json
python verificar_independiente.py --proyecto proyectos/mi_reto

Abre los archivos de salida

catalogo.jsonl: texto y fuente
candidatos.jsonl: cifras, fechas y referencias
catalogo.parquet: tabla
manifest.json: hashes
indice.json: vectores

Modifica un solo parámetro

En config.json, cambia ocr.psm de 6 a 11. Guarda la salida anterior, procesa e indexa otra vez. Compara textos sin alterar la imagen original.

Transferencia real: sustituye las dos fuentes por una imagen y un audio propios o autorizados, y repite el proceso. No atribuyas a un mismo hecho archivos no relacionados.
