02

Aprende a abrir fotografías

Escribe Path e Image.open. Observa tamaño y formato y muestra una foto real. Cambia el nombre del archivo para demostrar que el procedimiento sirve para otra fuente.

from pathlib import Path
from PIL import Image
ruta = Path("datos/raw/fotos/eltiempo_006.webp")
imagen = Image.open(ruta)
print(imagen.size)
03

Crea OCR sobre un acta SECOP

Inspecciona visualmente el total, descuento y neto de la primera página. Escribe una llamada a Tesseract desde Python. No publiques nombres ni cuentas.

import pytesseract
texto = pytesseract.image_to_string(
    pagina, lang="spa", config="--psm 6"
)
04

Detecta cuándo OCR no es adecuado

Aplica Tesseract a una imagen con letreros y a otra con viviendas sin texto. Cambia PSM de 6 a 11. Explica por qué extraer letras no equivale a interpretar una escena.

for psm in [6, 11]:
    print(psm, pytesseract.image_to_string(
        pagina, lang="spa", config=f"--psm {psm}"
    )[:100])

Escucha y transcribe voz humana

Descarga con control SHA el Parquet real PolyAI MINDS-14 es-ES, CC BY 4.0. Escucha una voz y escribe la transcripción con Whisper tiny. Contrasta contra la referencia del corpus.

from faster_whisper import WhisperModel
modelo = WhisperModel("tiny", device="cpu", compute_type="int8")
segmentos, info = modelo.transcribe(str(wav), language="es")
07

Construye el catálogo ETL

Escribe bucles y diccionarios de Python. Guarda un JSONL por líneas y un Parquet por columnas, siempre con el origen y SHA-256. No mezcles las actas, las fotografías y los audios como si fueran un único evento.

registro = {
    "archivo": str(ruta),
    "modalidad": "fotografia",
    "sha256": sha256(ruta)
}
08

Demuestra que aprendiste

En el mismo cuaderno, baja a FASE 2. Cambia N_ACTAS=5 → 30, N_FOTOS=8 → 62, N_VISION=8 → 62 o N_ASR=3 → 30. Registra qué cambió, cuánto tardó, cuál fue el resultado, cómo lo verificaste y qué limitación descubriste. El visor permite abrir cualquier fuente.

Protección de fuentes: los documentos SECOP pueden contener datos personales, las fotografías de El Tiempo conservan derechos de sus autores y las voces MINDS-14 son un corpus bancario independiente con licencia CC BY 4.0. Nunca inventes relaciones entre fuentes.
