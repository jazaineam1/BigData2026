Desplegar Elasticsearch Serverless

Tutorial operativo de la sesión. Está diseñado para repetir el despliegue sin depender del docente: crear proyecto, obtener credenciales, conectar Colab, crear índice, observar el analyzer, cargar 1.994 documentos y comprobar que quedaron en el motor.

Verificación documental: 23-sep-2026. La ruta principal sigue el quickstart oficial “Keyword search with Python”. Elastic recomienda Serverless como una forma simple de empezar. La interfaz puede cambiar de posición; si un botón no aparece exactamente donde se muestra aquí, usa el buscador global de Elastic para localizar API keys o Index Management.

Antes de empezar

No necesitas instalar Elasticsearch localmente. Tampoco necesitas Bash, Docker o una VM. Para la clase usamos navegador + Colab + un proyecto Elasticsearch.

La documentación oficial muestra actualmente una prueba de 14 días para usuarios nuevos; la disponibilidad depende de la cuenta y puede cambiar. Si tu cuenta no puede crear proyecto, trabaja con un compañero o usa la contingencia BM25 local y documenta la limitación.

1 · Entra a Elastic Cloud

Abre cloud.elastic.co e inicia sesión.

Busca la opción para crear un proyecto nuevo y elige el tipo Elasticsearch.

Evidencia: puedes ver el nombre de tu proyecto y entrar a él.

2 · Conserva la Project URL

Dentro del flujo de inicio/keyword search, Elastic muestra la URL que usará el cliente. Copia la Project URL completa, empezando por https://.

Esquema conceptual: esta URL identifica el servicio. No es tu API key y no es una contraseña.
Evidencia: tienes una URL HTTPS que podrás pegar en Colab.

3 · Crea una API key del proyecto

Usa la opción Create an API Key del flujo de búsqueda o busca API keys dentro del proyecto. Para esta práctica, la clave debe poder crear/usar el índice de tu equipo.

No uses una clave pegada en el código. El cuaderno la pide con getpass().

Distinción: Elastic también tiene Elastic Cloud API keys para administración a nivel de Cloud. En esta clase usa la clave de acceso al proyecto Elasticsearch que te entrega el flujo del proyecto.
Evidencia: tienes una clave guardada temporalmente y no la publicaste.

Regla de seguridad

Una API key es un secreto. No la pongas en GitHub, capturas, archivos de entrega ni mensajes del grupo. Si se expone, revócala y genera otra.

5 · Instala el cliente oficial

!pip -q install -U elasticsearch pandas tabulate

El paquete elasticsearch es el cliente Python oficial. El curso no implementa HTTP manualmente porque hoy queremos aprender búsqueda, no reinventar el cliente.

Evidencia: la celda termina sin error.

6 · Conecta y prueba

client = Elasticsearch(endpoint, api_key=api_key)
client.info()

La prueba de conexión ocurre antes de crear índice o escribir queries.

Evidencia: aparece “Conexión verificada” y el notebook cambia a Modo: Elasticsearch real.

7 · Crea tu índice personal

El notebook convierte tu alias a un nombre seguro como:

s07-compras-claras-equipo-demo

Así varios estudiantes pueden compartir un proyecto sin sobrescribir el mismo índice.

Evidencia: aparece “Índice creado: True ...”.

8 · Observa el analyzer real

client.indices.analyze(
    index=INDEX_NAME,
    analyzer="spanish",
    text="Servicios de mantenimiento de las aeronaves"

No memorices los tokens: compáralos con la frase de entrada y explica qué transformaciones notas.

Evidencia: el notebook imprime Tokens Elastic: [...].

9 · Carga el corpus con bulk

El notebook prepara 1.994 documentos únicos y usa elasticsearch.helpers.bulk.

Evidencia: con el corpus principal debes ver Documentos indexados: 1994 y Errores bulk: 0.

10 · Comprueba desde el motor

client.count(index=INDEX_NAME)

La carga no está terminada hasta que el índice confirma la misma cantidad que el DataFrame.

Evidencia: Conteo local: 1994, Conteo Elasticsearch: 1994, ¿Coinciden?: True.
