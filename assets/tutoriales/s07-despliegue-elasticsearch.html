Guía de despliegue: Elasticsearch desde cero

Esta guía está pensada para estudiantes con Python básico/intermedio y poca experiencia en cloud. No exige Bash. La ruta principal es navegador + Elastic Cloud + Google Colab.

Antes de crear cuentas

Si no tienes Elastic Cloud listo, puedes completar la sesión con BM25 local en el cuaderno principal. El despliegue real se hace cuando tengas endpoint y API key.

Ruta de despliegue

1. Entrar a Elastic Cloud

Usa una cuenta personal o institucional. Crea un proyecto/deployment de prueba. Conserva el nombre del proyecto para tu hito.

2. Copiar el endpoint

Busca el endpoint de Elasticsearch. Debe empezar por https://. No uses URL de Kibana como si fuera endpoint de Elasticsearch.

3. Crear API key

Crea una API key para pruebas. No la publiques en GitHub, capturas de pantalla o entregas. En Colab pégala con getpass() o Colab Secrets.

4. Abrir el cuaderno de despliegue

Abrir cuaderno S07B

Ejecuta instalación, carga del corpus, conexión, creación del índice, carga bulk y búsqueda.

5. Verificar conexión

client.info()

Si responde con información de versión/cluster, la conexión existe. Si falla, revisa la tabla de errores.

6. Crear índice y mapping

El mapping define cómo se interpreta cada campo. La descripción se analiza como text; el ID y la entidad se tratan como keyword.

7. Cargar documentos con bulk

El patrón bulk es la forma profesional de cargar muchos documentos. En clase usamos pocos, pero el patrón escala.

8. Ejecutar búsqueda

Usa multi_match sobre nombre_proceso y descripcion. Guarda top 5, score, ID y URL.

9. Comparar una modificación

Cambia una sola cosa: consulta, filtro o ponderación. Explica qué cambió en el ranking.

10. Cerrar responsablemente

Si estás usando un proyecto de prueba, revisa costos o elimina recursos que no necesites.

Regla de seguridad

Nunca subas API keys al repositorio. Si una clave se publica por error, revócala y crea otra.
