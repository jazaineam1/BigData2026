Guía integral S07 · desplegar Elasticsearch y buscar con BM25

Esta guía está escrita para estudiantes que saben ejecutar Python en Colab, pero no necesariamente administran nube, Bash o servidores. El objetivo es que puedan repetir solos el despliegue mínimo.

Paso 0 · Antes de crear nada

Decide si trabajarás con el JSONL exportado en S6 o con el respaldo del cuaderno. El respaldo sirve para aprender; si usas tu archivo S6, la evidencia queda mejor trazada.

Paso 1 · Crear el proyecto en Elastic Cloud

  1. Entrar a Elastic Cloud.
  2. Crear un proyecto de Elasticsearch/Serverless o deployment equivalente.
  3. Esperar a que el servicio esté listo.
  4. Copiar el endpoint HTTPS.
  5. Crear una API key para conectarte desde Python.
Regla de seguridad. Si la API key aparece en GitHub, en un pantallazo o en una entrega pública, se revoca y se crea otra.

El patrón seguro usa getpass(). La clave se escribe en ejecución, pero no queda guardada en el notebook.

Paso 3 · Crear índice y mapping

No subas datos “a ciegas”. Primero define qué campos son texto y cuáles son exactos.

mapping = {
  "mappings": {"properties": {
    "id_proceso": {"type":"keyword"},
    "entidad": {"type":"keyword"},
    "nombre_proceso": {"type":"text", "analyzer":"spanish"},
    "descripcion": {"type":"text", "analyzer":"spanish"},
    "url_secop": {"type":"keyword", "index": False}
}}}

INDEX = "s07_compras_claras"
if client.indices.exists(index=INDEX):
    client.indices.delete(index=INDEX)
client.indices.create(index=INDEX, **mapping)

Paso 4 · Cargar documentos con bulk

from elasticsearch.helpers import bulk
acciones = []
for d in corpus.to_dict("records"):
    acciones.append({
      "_index": INDEX,
      "_id": d["id_proceso"],
      "_source": d
    })
ok, errores = bulk(client, acciones, refresh=True, raise_on_error=False)
print(ok, len(errores))

Si ok es mayor que cero, ya tienes un índice cargado.

Paso 5 · Consultar y leer resultados

query = {
  "query": {"bool": {
    "must": [{"multi_match": {
      "query": "mantenimiento aeronaves",
      "fields": ["nombre_proceso^2", "descripcion"]
    }}],
    "filter": [{"term": {"entidad": "FUERZA AEROESPACIAL COLOMBIANA"}}]
  }},
  "highlight": {"fields": {"nombre_proceso": {}, "descripcion": {}}},
  "size": 5
}
resp = client.search(index=INDEX, **query)

Lee tres cosas: _score, documento y highlight. El score ordena, pero el highlight ayuda a entender por qué.
