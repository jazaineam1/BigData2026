Tokenizer Lab

Escribe una frase, cambia el tokenizer y los filtros, y observa paso a paso: texto → tokenizer → filtros → tokens. Esto no reemplaza Elasticsearch; es un simulador pedagógico para entender el mecanismo.

1 · Escribe o elige un texto

Idea clave

Un tokenizer decide cómo partir el texto. Un token es cada unidad resultante. El número de tokens no siempre coincide con el número de palabras humanas.
