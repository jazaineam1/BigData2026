S10 · Implementa E → T → L con imágenes reales

Laura necesita preparar las imágenes de las noticias de contratación para un catálogo reutilizable. Trabajas en VS Code con Python: primero una imagen, después la misma operación por micro-lotes.

Entrada: recibe S10_entradas_reales.zip del docente. Contiene 32 imágenes reales y el contexto del corpus, adquiridos una vez. No hay una descarga pública automática del periódico ni sustitutos sintéticos. El proyecto público contiene código; las entradas se distribuyen por la vía docente.

Antes del encuentro: abre el proyecto, crea el entorno Python y ejecuta python -m pip install -r requirements.txt. El README explica Windows, Linux y macOS. En clase selecciona el intérprete preparado; no cambiamos de plataforma a mitad del recorrido.

1 · E: extrae y localiza el origen

Haz: abre la carpeta en VS Code y ejecuta con la ruta de tu ZIP real. El ejemplo asume que está en la carpeta superior:

python main.py extraer --entrada ../S10_entradas_reales.zip --trabajo work/s10 --cantidad 32

Para qué: consolidar los originales y verificar que corresponden al snapshot recibido.

Evidencia exacta: E · extracción, imagenes_reales_del_lote, origen: eltiempo_real. El catálogo observado separa 987 artículos, 5.152 referencias y 4.071 URLs. Abre un RAW y su registro en config/jobs.json.

Si te atascas

Cambia solo la ruta --entrada; usa comillas si tiene espacios. Si el original o su huella no coinciden, recupera la entrada docente: el programa no genera otra imagen.

2 · Lee e implementa una transformación

Haz: abre paso_a_paso.py. Identifica E, T y L; ejecuta y cambia un solo parámetro:

python paso_a_paso.py --trabajo work/s10 --posicion 1 --lado 640
python paso_a_paso.py --trabajo work/s10 --posicion 1 --lado 320

Para qué: entender Image.open, orientación, thumbnail, guardado separado y carga de metadata antes de automatizar.

Evidencia exacta: tabla con dimensiones y bytes; RAW conservado: True; original y derivados en rutas distintas. Abre ambos en VS Code. Convertir WEBP a JPEG puede aumentar los bytes: observa tu resultado.

Si te atascas

La posición empieza en 1. Ejecuta E antes del ejemplo. thumbnail cambia la imagen en memoria; guardar en otra ruta conserva el RAW.

3 · T: aplica la operación por micro-lotes

Haz: ejecuta el primer grupo y continúa los pendientes:

python main.py transformar --trabajo work/s10 --perfil catalogo640 --lote 16 --hasta 16
python main.py transformar --trabajo work/s10 --perfil catalogo640 --lote 16

Para qué: recorrer archivos sin mantener todas las imágenes decodificadas juntas y conservar estado por trabajo.

Evidencia exacta: primera ejecución con 16 DONE/16 PENDING para una entrada de 32. La continuación procesa las restantes y declara skipped_verified para las previas revalidadas.

Si te atascas

Lee FAILED en state/checkpoint.json. No edites el estado para aparentar éxito. Para otra selección de entrada usa otra carpeta de trabajo.

4 · Decide y compara un perfil

Haz: usa los mismos archivos y ejecuta otra configuración:

python main.py transformar --trabajo work/s10 --perfil vista320 --lote 16

Para qué: ver la consecuencia de una decisión pequeña y descartar una alternativa por el uso que necesitas.

Evidencia exacta: dos perfiles en el checkpoint; derivados con dimensiones y bytes propios. Conserva ambas salidas. Lote y trabajadores son parámetros distintos; más trabajadores no garantizan aceleración.

Si te atascas

Los perfiles disponibles son vista320, catalogo640 y detalle1024. Compara el mismo conjunto, no cambies además de entrada.

5 · L: carga, relee y consulta

Haz: consolida y vuelve a abrir la salida:

python main.py cargar --trabajo work/s10 --zip paquete_s10.zip
python main.py verificar --trabajo work/s10

Para qué: dejar metadata consumible por otro proceso y comprobar el contenido, no solo el nombre del archivo.

Evidencia exacta: L · carga y ok: true; outputs/assets.jsonl, outputs/assets.parquet, manifest_s10.json y checks/quality_report.json. Consulta la tabla por perfil o article_id.

Si te atascas

Completa pendientes de todos los perfiles antes de cargar. Si falta el motor Parquet, selecciona el intérprete preparado e instala requirements. Un paquete parcial no se declara completo.

6 · Repite, conserva y traslada

Haz: verifica desde otra carpeta y repite sobre resultados completos:

python main.py verificar --zip paquete_s10.zip --destino restaurado_s10
python main.py transformar --trabajo work/s10 --perfil catalogo640

Para qué: comprobar portabilidad y reejecución sin generar trabajo duplicado.

Evidencia exacta: ok: true desde una carpeta nueva; después processed_now: 0 y skipped_verified: 32 si todo sigue válido. Actualiza la carga después de cambiar métricas.

En main.py decidir, elige posición propia, perfil, alternativa y límite mediante códigos. Los ceros dejan pendientes; no son respuestas correctas preseleccionadas. El README explica las opciones. Vuelve a cargar para incluir la decisión en el ZIP.

Si te atascas

El destino de restauración debe estar vacío. El checkpoint solo sobrevive si sus archivos siguen disponibles; para otro equipo conserva el paquete. No se acredita una nota por marcar este checklist.
