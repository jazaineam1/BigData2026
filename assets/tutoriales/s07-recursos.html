Sesión 7 · Elasticsearch y BM25

Del vecindario al texto

Entrada única para estudiantes. La sesión está pensada para un grupo de tercer semestre con Python medio, SQL medio, poco Bash y poca experiencia cloud. Empieza por la presentación, ejecuta el cuaderno y usa la guía de despliegue cuando tengas Elastic Cloud listo.

1 · Presentación guiada

Explicación completa: contexto, BM25, Elasticsearch, despliegue, errores esperados y entrega.

2 · Cuaderno principal

Laboratorio con corpus, BM25 local, consultas, experimento A/B y generación de evidencia.

3 · Cuaderno de despliegue

Ruta paso a paso para conectar Elastic Cloud desde Python: endpoint, API key, índice, bulk y búsqueda.

4 · Guía de despliegue

Checklist visual para crear o usar Elastic Cloud sin depender de Bash ni de administración avanzada.

5 · Checklist de laboratorio

Lista de verificación para completar la práctica y no olvidar evidencia, límite y motor realmente usado.

6 · Corpus de respaldo

Datos mínimos para que la clase no se caiga si el archivo de S6 no está disponible.
Regla de honestidad técnica: si ejecutas solo BM25 local, decláralo. Si ejecutas Elastic Cloud, guarda evidencia de conexión, índice y consulta. Un score alto no demuestra irregularidad.
