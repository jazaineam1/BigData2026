Atlas: solo lo que falta

No repetimos registro, clúster ni carga. Ya tienes compras_claras con noticias y entidades_noticias. Hoy terminamos consultas, pipeline y una vista que el cuaderno sí consumirá.

Punto de partida

987 noticias + 142 entidades ya cargadas.

Producto obligatorio

menciones_clasificadas.

Regreso

Vuelves al mismo cuaderno S5; no abras otro Colab.

Paso 1

Comprueba que estás en la base correcta

  1. Abre Data Explorer o Browse Collections.
  2. Selecciona compras_claras.
  3. Debes ver noticias y entidades_noticias.
OJO. Si no aparecen, no crees otra base: vuelve al clúster que usaste en S4.
Captura del curso: las dos colecciones que deben existir antes de continuar.
Paso 2 · calentamiento

Una consulta corta antes del pipeline

En noticias → Documents ejecuta:

{"titulo":{"$regex":"\\bdian\\b","$options":"i"}}
Esperado: 1 coincidencia.
La idea es recordar la diferencia: un filtro decide qué documentos ves; un pipeline encadena transformaciones.
Captura del curso: el patrón cambia la evidencia.
Paso 3

Abre Aggregations en modo Texto

  1. Abre noticias → Aggregations.
  2. Cambia al ícono </> — modo Texto.
  3. Pega las cuatro etapas juntas.
  4. Pulsa Run.
  5. Save → Save as → resumen-secciones-v1.

Paso 5

Crea menciones_clasificadas

  1. Abre entidades_noticias → Aggregations.
  2. Modo Texto </>.
  3. Pega el pipeline versionado.
  4. Run.
  5. Save → Save as → clasificar-menciones-v1.
  6. Con el mismo pipeline: Save → Create view → menciones_clasificadas.
