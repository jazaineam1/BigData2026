Extensión profesional · qué haría un equipo de búsqueda después

Ranking Evaluation API

Formaliza juicios de relevancia sobre consultas típicas y calcula métricas de recuperación a escala.

Search Profiler

Sirve para inspeccionar cómo se ejecuta una consulta y diagnosticar costo/tiempo cuando la búsqueda deja de ser un ejercicio pequeño.

Search UI

Convierte el motor en una experiencia de producto: caja de búsqueda, filtros, facets, paginación y estado de consulta.

Semantic / hybrid

Cuando las palabras ya no bastan, combina búsqueda lexical con recuperación por significado. Ese es el puente a la siguiente etapa del curso.
