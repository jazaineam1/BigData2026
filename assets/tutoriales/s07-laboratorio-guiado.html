D4

API _analyze · de cero a una petición real

Antes de responder, aprende qué es una API, qué significa POST y cómo abrir Console en Elastic.

1 · Qué es una API

Una API es una forma acordada de pedirle una operación a otro sistema. En este caso, tú envías una solicitud a Elasticsearch y Elasticsearch devuelve una respuesta JSON.

Túsolicitud
→
API Elasticsearch/_analyze
→
Motoranaliza texto
→
Respuestatokens[]

2 · Qué significa POST

POST es un método HTTP: una palabra que acompaña la solicitud e indica el tipo de operación. Aquí lo usamos para enviar un cuerpo JSON con el analyzer y el texto.

La Analyze API también admite GET. En S07 usamos POST porque hace visible la estructura método + ruta + cuerpo.

3 · Qué es la ruta

/_analyze es la ruta de la operación. No es una página web para abrir con clic: es el nombre de una API de Elasticsearch.

No usamos s07-demo/_analyze todavía porque ese índice se crea más adelante.

4 · Cómo abrir Console

  1. Entra a tu proyecto de Elastic.
  2. Abre el menú de navegación o el buscador global.
  3. Busca Dev Tools y entra a Console.
  4. En el editor izquierdo pega la solicitud.
  5. Pulsa el botón ▶ para ejecutarla.
  6. Lee la respuesta JSON en el panel derecho.
Si ves una Console persistente en la parte inferior del proyecto, también puedes usarla.
ELASTIC CONSOLE · CÓPIALO ALLÍ, NO EN COLAB
POST /_analyze
{
  "analyzer": "standard",
  "text": "Quick brown fox"
}
Qué deberías ver: una respuesta con tokens[]. Con este ejemplo aparecerán tokens como quick, brown y fox.
