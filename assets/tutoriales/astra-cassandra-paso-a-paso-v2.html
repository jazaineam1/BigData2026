Paso 5

Crea la tabla y conserva el contexto de Atlas

USE compras_claras;

CREATE TABLE IF NOT EXISTS prioridades_por_corte_departamento (
  corte date,
  departamento text,
  valor_base bigint,
  id_proceso text,
  entidad text,
  noticias_entidad int,
  nivel_menciones text,
  estado_revision text,
  url_secop text,
  criterio text,
  PRIMARY KEY ((corte, departamento), valor_base, id_proceso)
) WITH CLUSTERING ORDER BY (
  valor_base DESC,
  id_proceso ASC
);
(corte, departamento)

localiza una partición.

valor_base DESC

prepara el top por valor.

noticias / nivel

contexto que viajó desde Atlas; no forma la PK.

INSERT + SELECT con una fila

(corte,departamento,valor_base,id_proceso,entidad,
 noticias_entidad,nivel_menciones,estado_revision,url_secop,criterio)
VALUES (

 'CO1.REQ.5407319','MINISTERIO DEL DEPORTE',
 3,'baja','pendiente','',
 'entidad en prensa; contratación directa; 0 respuestas'
);

SELECT id_proceso,entidad,valor_base,
       noticias_entidad,nivel_menciones,estado_revision
FROM compras_claras.prioridades_por_corte_departamento
WHERE corte='2026-09-03'
  AND departamento='Distrito Capital de Bogotá'
LIMIT 5;
Esperado: aparece la fila insertada. Los campos de prensa son contexto, no prueba de irregularidad.
Paso 7

UPDATE: escribe y vuelve a leer

UPDATE compras_claras.prioridades_por_corte_departamento
SET estado_revision='en_revision'
WHERE corte='2026-09-03'
  AND departamento='Distrito Capital de Bogotá'
  AND valor_base=168750000
  AND id_proceso='CO1.REQ.5407319';

SELECT estado_revision
FROM compras_claras.prioridades_por_corte_departamento
WHERE corte='2026-09-03'
  AND departamento='Distrito Capital de Bogotá'
  AND valor_base=168750000
  AND id_proceso='CO1.REQ.5407319';
Control: el segundo comando debe mostrar en_revision. Imprimir “actualizado” sin releer no demuestra el cambio.
Error plantado

La columna existe, pero la tabla no localiza por ella

SELECT *
FROM compras_claras.prioridades_por_corte_departamento
WHERE entidad='MINISTERIO DEL DEPORTE';
Predice antes de ejecutar. La tabla está particionada por corte + departamento. Que `entidad` exista no la convierte en clave de acceso.
Decisión: si buscar por entidad se vuelve una pregunta frecuente, diseña otra tabla para ese patrón. No uses ALLOW FILTERING como parche conceptual.
Paso 8

Connection details → SCB + token

  1. Vuelve a la base.
  2. Abre Connection details.
  3. En Get Secure Connect Bundle, descarga el SCB.
  4. Genera un application token para la base.
  5. Conserva el SCB como archivo .zip.
SECRETO. Token y SCB no se publican en GitHub, correo, chat ni capturas.

Prueba de corrección: los IDs y su orden en Cassandra deben ser exactamente iguales al top 5 calculado con pandas.
No confundas esto con rendimiento. Coincidencia de resultados prueba corrección de la ruta; no demuestra que Cassandra sea más rápido ni necesario para 77 filas.
